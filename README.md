# じゃが畑ファクトリー

畑でじゃがいもを育てて収穫し、工場でスティックにカットしてカップに詰め、トラックで出荷するまでを遊べる、スマホ縦画面向けの3D箱庭ゲームです。

**▶ プレイ：https://kenkenta51-max.github.io/sample-game/**

## あそびかた

1. **畑で育てる** — 空いている畑をタップで種まき、水マークをタップで水やり（途中でもう1回）、実ったらタップで収穫。
2. **ブレンドで味をつくる** — にんじん＋パセリをブレンドするとサラダ味パウダー×2。チーズ味の日はウシのミルクを使います。
3. **タイミングよくカット** — 工場で針が赤い「ぴったり」ゾーンに重なった瞬間にタップ。
4. **カップに詰めて出荷** — 8本でカップ完成。全部ぴったりなら PERFECT CUP、10コンボで FEVER（得点2倍）。
5. **夕方に1日おわり** — 目標カップ数で★1、スコアで★2・★3。

左右スワイプで 畑 ⇄ 工場 を行き来できます。ときどき実るゴールデンポテトを収穫すると LEGENDARY!

## 内容

- 全6日のステージ（DAY3でチーズ味、DAY5でじゃがバター味が解放）
- 畑担当のポテくん、工場担当のキャロちゃんが作業するキャラクター
- タイトル画面に約60秒の自動デモ。途中でタップすると参加できます

## 技術

1ファイルの `index.html` で動きます（ビルド不要）。React 18 + htm、Three.js r128 を CDN から読み込んでいます。
